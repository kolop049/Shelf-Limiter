# Changelog

## 1.0.0 - 2026-07-31

- Added per-resource maximum fields to vanilla shelf storage settings.
- Added automatic per-resource capacity capping.
- Added exact hauling limits that account for incoming haulers.
- Added removal of existing excess items when limits are lowered.
- Added save-game persistence.
- Added support for vanilla 1x1 and 1x2 shelves on RimWorld 1.6.
